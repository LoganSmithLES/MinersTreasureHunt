# MinersTreasureHunt

Miner’s Treasure Hunt is a console adventure game written in C. You move through a 12x12 mine using WASD controls, collect ores (gold, iron, cobalt, nickel), manage limited inventory space, and use the shop to sell resources or buy upgrades. As levels progress, mine layouts become tougher and your goal is to gather enough value to pay the final exit cost and finish the run with a strong leaderboard score.
